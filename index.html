Instrucciones para programar NFC (app gratuita)
  1. Descarga NFC Tools en Android o iOS.
  2. Abre → Write / Escribir → Add a record → Social network → WhatsApp.
  3. Introduce tu número con +código país.
  4. Toca Write y acerca el tag NFC al móvil.
  5. ¡Listo! (Si no ves WhatsApp, usa "URL" y pega el enlace copiado).
